# Blueprint Kanban - 业务逻辑

## 核心闭环

### 1. 画布导航
```
用户 → 滚轮缩放 / Alt+拖拽平移 → camera {x,y,zoom} 更新 → localStorage 持久化
```

### 2. 节点创建
```
右键空白处 / 双击空白处 → ContextMenu / 直接创建 → createNode(type, x, y)
→ 网格对齐 (snapToGrid 20px) → 渲染到画布
```

### 3. 节点拖拽
```
鼠标按下节点 → setDraggingId → mousemove 计算 delta → snapToGrid → 实时更新 x,y
→ mouseup → updateNode({x,y}) → 持久化
```

### 4. 节点连线
```
拖拽节点右侧连接 handle → setConnectingFrom → mousemove 渲染虚线
→ 释放到另一节点 → connectNodes(fromId, toId) → 渲染贝塞尔曲线
```

### 5. 计时器逻辑
```
点击 timer 节点播放按钮 → toggleNodeTimer(nodeId)
→ 停止其他运行中 timer（全局互斥）→ startTimer / stopTimer
→ setInterval 1000ms 更新 displayTime
```

### 6. 节点删除
```
选中节点 + Delete 键 / 点击 X 按钮 → deleteNode(id)
→ 级联删除相关 connections（双向清理）
```
