# Blueprint Kanban - 数据模型

## 存储方案
- **backend**: `localStorage` (STORAGE_KEY = `'blueprint-data-v3'`)
- **format**: JSON
- **no cloud dependency** (purely local)

## 实体定义

### BlueprintProject
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | `proj-{timestamp}-{random}` |
| name | string | 项目名称 |
| color | string | Hex 颜色 |
| order | number | 排序 |
| camera | {x,y,zoom} | 画布相机位置（按项目持久化）|
| showGrid | boolean | 是否显示网格 |

### BlueprintNode (核心)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | `node-{timestamp}-{random}` |
| projectId | string | 所属项目 |
| type | NodeType | `'task' | 'timer' | 'note'` |
| title | string | 节点标题 |
| content? | string | 额外内容（note 用）|
| x, y | number | 画布坐标（px） |
| width, height | number | 节点尺寸 |
| color | string | Hex 颜色 |
| completed? | boolean | task 完成状态 |
| timerData? | {isRunning, totalSeconds, startedAt} | timer 专用 |
| connections | string[] | 连线目标节点 ID 列表 |
| createdAt | string | ISO8601 |

### NodeType 默认尺寸
- task: 240x64
- timer: 160x44
- note: 200x120

## 命名公约
- ID 前缀: `proj-`, `node-`
- localStorage key: `blueprint-data-v3`
- 文件名: kebab-case
- 组件名: PascalCase
- 类型名: PascalCase + Blueprint 前缀区分旧模型
