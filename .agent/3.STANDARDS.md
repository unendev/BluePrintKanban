# Blueprint Kanban - 工程标准

## 决策优先级
1. **质量 > 速度** - 宁可多回合也要优雅方案
2. **去硬编码** - 尺寸、颜色等配置收束到 store 的 DEFAULT_* 常量
3. **单一数据源** - 所有状态以 localStorage 为准，React state 为派生

## 绝对禁令
- [ ] 禁止在 model 变更中使用 db push（本项目无 db）
- [ ] 禁止散落配置 - 所有 DEFAULT_SIZES, DEFAULT_COLORS 必须在 store 中定义
- [ ] 禁止内存泄漏 - setInterval 必须配 clearInterval

## 非侵入式运维
- localStorage key 带版本号 (`blueprint-data-v3`)，方便未来迁移
- 相机状态按项目隔离持久化，切换项目不丢失视图
- 网格对齐可开关，用户偏好持久化到 project.showGrid
